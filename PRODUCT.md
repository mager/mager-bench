# Product

Mager-bench is Mager's small, public benchmark for coding models. A visitor
should understand the task, inspect the exact expected result, then inspect
what a model actually returned. The active version is 1.2.

The user explicitly requested a fresh benchmark with less AI-written marketing
language and no active Counterexample Lab. The new suite uses familiar programs
with complex details: split a bill, clean a CSV, and find a meeting time.
Speed is a product requirement. All evals use the lowest supported reasoning
effort, with short bounded calls and local deterministic checks, never model
judges. There are 36 public checks and three subject calls maximum.

The site serves curious builders reading results on desktop or phone. Preserve
the dark setting; replace the old basketball metaphors and condensed display
headlines with a straightforward software test report. The useful content is
inputs, expected outputs, source code, actual results, failures, and timing.
Use plain task names and short explanations. Do not add promotional slogans,
fictional rankings, live statuses, or simulated model results.

GPT-6 Sol was requested as the first v1.2 subject. The subscription CLI rejected
it on October 2, 2026. Its failed attempt is public and unscored. Do not substitute
a different model under its name or turn provider failures into zero scores.

Preserve v1.1 and the original thirteen-task benchmark in the archive, including
all prompts, raw answers, scoring rules, run artifacts, and existing detail URLs.
Never blend scores across versions. A single run is not a reliable ranking.

Interactive examples are published test fixtures, clearly distinguished from
model outputs. Source code and data must remain inspectable. Navigation, case
selection, disclosures, keyboard focus, and phone layouts must work.

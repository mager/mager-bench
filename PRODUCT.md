# Product

Mager-bench 2.0 tests whether a coding agent can repair code and handle a changed
requirement. Three small JavaScript repositories, two work orders each, 192
checks, and ten minutes of agent time. Codex CLI uses the local ChatGPT
subscription and the lowest supported effort. No model judge.

The site serves builders on desktop and phone. Keep the home page very short:
what the benchmark does, its tasks, and saved results. Put exact contracts,
code, failures, and methodology behind links or disclosures. Use plain language.
No slogans, invented scores, fake live states, or rankings from one run.

Keep the existing dark report style. The v2 work changes the benchmark, not the
visual system. Full rules are in `docs/mager-bench-2.0.md`. Version 2 has seeded
inputs, three workload scales, source snapshots, and local replay. It does not
claim that these public synthetic projects will remain difficult for ten years.

Preserve v1.3 and all older suites, scores, artifacts, and existing detail URLs.
Never blend versions. Failed model sessions remain unscored. Reference programs
are fixtures, not model results. Compare only matching suite hash, seed, level,
budget, and runtime; use repeated seeds before drawing model comparisons.
